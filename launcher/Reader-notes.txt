D65 Studio 0.3.0 resident reader

See Resident-driver.txt for the complete ABI, memory contract and test limits.
The desktop app embeds reader.bin. End users need no assembler or added tools.
START installs the entire reader at $1600 and the catalogue at $87FE000.
Code/buffer/mailbox reserve $1600-$1EFF; Attic workspace reserves the top 64 KiB
at $87F0000-$87FFFFF. BASIC graphics banks are not reserved or used.

Menu programs have a BASIC entry at $2001, max 55,041 bytes including address.
The normal-sector area is shared between START and payloads, adding almost
800 KB over the old two-payload-bank design. Directory blocks remain T40/S3-39.
Payload chains may cross the 0-39 / 40-79 / 80-119 sector groups. Standard BAM
bits are marked unavailable and the app treats the custom compilation read-only.

The callable service stays resident after launch. It supports whole-file reads
by exact name or index. It does not install automatic KERNAL LOAD/OPEN hooks.

Developer rebuild:
  ./build-reader.sh /path/to/acme
Then rebuild the Rust application to embed the new bytes.

Historical reader documentation and hardware tests in verification/launcher
refer to earlier versions. They must not be presented as hardware validation
of this reader. New evidence is in verification/resident-driver.
